# Qrypt documentation

Use these guides to get from your first QR code to production integration. You do not need to understand the QR encoding algorithm to use Qrypt.

1. [Getting started](GETTING-STARTED.md) — set up Qrypt and create your first symbol.
2. [Generate QR codes](GENERATING.md) — choose data, error correction and version.
3. [Export images](EXPORTING.md) — SVG, PNG, RGBA pixels, downloads.
4. [Styling and logos](STYLING-AND-LOGOS.md) — customize colors and module shapes safely.
5. [Common payloads](PAYLOADS.md) — Wi-Fi, contacts, events, email, SMS, geo.
6. [Decode QR codes](DECODING.md) — matrices and raw image pixels.
7. [Advanced formats](ADVANCED.md) — binary, Kanji, GS1 and structured append.
8. [Signed QR codes](SECURE-QR.md) — issue and verify authenticated QR tokens.
9. [API reference](API.md) — imports, options, return types.
10. [Troubleshooting](TROUBLESHOOTING.md) — common errors and scanning tips.

**Compatibility:** QR Code Model 2, Versions 1–40, error correction L/M/Q/H. Pure TypeScript/JavaScript; no runtime npm dependencies. QR scanners vary, particularly with specialized payload formats and styled symbols.

> `@blcklab/qrypt` has not yet been published. Imports show the planned package API and work with a locally built `file:` installation.
